# Retired feature-list PDF

Historical record. Do not run or deploy these files.

`Workloop_Clinic_HRMS_Feature_List.pdf` describes the former Supabase application and includes
retired setup instructions. It is kept only as product-history evidence. Current features and
planned work live in `FEATURES_ROADMAP.md`.

`SUPABASE_PORTAL_MODULE_FEATURE_CATALOGUE.md` is a code-verified guide to the shared,
administrator, manager, and employee modules at the final Supabase reference commit. It separates
working source behavior from ideas that appeared only in the retired PDF.

`SUPABASE_UI_PARITY_SPECIFICATION.md` turns that verified feature catalogue into a presentation and
interaction contract for the current application. It records the historical portal layout, visual
tokens, responsive behavior, module controls, and UI states. Biometric integration and outbound
email notifications are explicitly outside its scope.

The Python generator that produced the PDF was retired in Part 13E. Rebuilding the PDF would make a
new obsolete instruction set, so the repository keeps only the digest-pinned historical output.
