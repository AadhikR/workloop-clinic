# Part 12F completion

Status: complete. The local gate and routed GitHub gate passed.

## Result

Part 12F moves approved CSV and SIF generation to the FastAPI migration application. Administrators
can download CSV files for the thirteen approved reports, the employee import template and employee
export, leave balances, attendance periods, roster months, and Nafis reports. The migration screens
now request those bytes from the server and save the response without rebuilding the file in the
browser.

The CSV renderer fixes column order, UTF-8 encoding, RFC 4180 quoting, CRLF line endings, empty null
values, and spreadsheet-formula protection. Only the roster compatibility export has a UTF-8 BOM.
Report exports retain the Part 12E source and filter rules. Export size is capped at 5,000 rows and
8 MiB.

The two SIF routes render full or rejected-entry output from the approved Phase 9 payroll
projection. EDR rows use the contract order, AED amounts use integer `ROUND_HALF_UP` rounding, the
SCR total is recomputed from the selected entries, output is ASCII, and every file ends with CRLF.
Preview parses the generated bytes and returns the same filename and source digest as the download.
Filenames come from source data and its digest, with no wall-clock or random input.

Alembic revision `d6f8a0c2e4b7` follows `c3e5a7b9d1f6`. It creates the fixed-purpose
`append_phase12_output_audit` function with the exact signature approved in Part 12A. The function
admits only the eight Part 12F action, entity, and format tuples. It verifies the runtime login,
administrator principal, selected branch, source state, digest syntax, renderer version, counts, and
result before it appends safe metadata. No output bytes, employee data, bank data, or filename enters
the audit log. A required audit failure denies delivery before streaming. No output-blob table was
added.
